# Kit oficial del reto

Copia aqui los archivos del kit de participantes **tal cual**:

- `events.jsonl`
- `manifest.json` (de aqui sale `evaluation_time`)
- `contratos.json`

`npm run decide` usa esta carpeta automaticamente si existe `events.jsonl`;
si no, usa `data/sample/` (datos inventados por el equipo para probar).

No subas aqui archivos reservados del jurado.
